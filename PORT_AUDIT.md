# Port verification notes

Updated September 7, 2026. This is an evidence log, not a declaration that the port is complete. The older completion percentages in TODO.md are not reliable verification.

## Current local batch

These changes are local and have not been deployed to GitHub Pages.

| Repeated possession | A turret's cached ghost controller retained its released flag on re-possession. Release restoration was deferred to a Game.tsx branch that only accepted enemy-type targets. | Touch ownership | Legacy window gestures overwrote canvas slider/button input, and ending one finger could clear another held control. Controls now exclusively own gameplay touches, retain each button until its last owner releases, and cancel held state on detach, blur or suspended gameplay. Overlay events are not consumed by gameplay controls. | Scaled-canvas event tests exercise concurrent slider/fly/stomp touches, cancellation, duplicate button owners, mouse/touch coexistence, and overlay gating. Physical-device/browser touch verification remains pending. |
| Mobile orb steering | The visible slider supplied no vertical direction, leaving the orb's keyboard-only directional substitute incomplete on touch. This is a web adaptation of the original tilt input, not a device-orientation implementation. | Touch events through CanvasControls → InputSystem → a real factory-spawned orb move it in all four cardinal directions. Handoff tests verify old touches cannot keep steering the replacement target. Browser lab check visually verified the pad and normal slider after expiry. A development-only timed canvas mouse-input check moved the real orb from y448 to y384 and confirmed upward input cleared on release, without changing actor state. Physical-device touch verification remains pending. |
| Controller input | Gamepad polling populated synthetic keys that gameplay actions never read. Direction reversals retained opposite keys, D-pad buttons were ignored, and disconnected controllers left held state behind. Gamepad actions now feed the shared input state, retain analogue movement, detect pre-connected pads, and clear only controller state on loss/access denial. Start is polled while paused and toggles once per press. | Simulated standard-controller tests cover stick reversal/deadzone, D-pad directions, jump/attack, pre-connected discovery, disconnect/access denial, keyboard/touch coexistence and keyboard remapping. Pause/resume wiring is source-checked; physical-controller and interactive pause verification remain pending. |
| Input frame edges | InputSystem cleared browser key press/release events at the start of the step before consumers could read them. Pending events now publish for one simulation step, with virtual fly/stomp buttons exposing the same edge API. | Tests cover held keys, OS repeat, complete taps between ticks, touch action edges and blur cancellation. Existing held-state gameplay behavior is preserved; this is not a claim that every gameplay action consumes the edge API. |
